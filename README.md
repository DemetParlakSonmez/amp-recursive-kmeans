# AMP Recursive K-Means

This repository contains the notebooks and datasets used to evaluate an
AMP-based recursive feature-selection workflow for colorectal cancer
classification.

## Method overview

The workflow in [`amp_recursive_kmeans.ipynb`](./amp_recursive_kmeans.ipynb)
performs the following steps:

1. Load a prepared dataset containing the `data`, `label`, and feature columns.
2. Standardize the feature columns with `StandardScaler`.
3. Compare the two label groups with Welch's independent-samples t-test.
4. Correct the resulting p-values with the Benjamini-Hochberg FDR procedure.
5. Transpose the feature matrix and group features with K-Means.
6. Combine the t-statistics within each cluster, calculate a two-sided
   cluster-level p-value, and apply FDR correction.
7. Retain features from significant clusters and repeat the process at the
   configured iteration checkpoints.
8. Evaluate each selected feature set with a support vector machine using
   stratified 10-fold cross-validation.

The notebook currently contains the reproducible `k = 10` configuration:

```python
MANUAL_K_CLUSTERS = 10
CHECKPOINTS = [2, 3, 4]
```

The implementation uses a Benjamini-Hochberg false discovery rate threshold
of `FDR_ALPHA = 0.05` when selecting significant clusters. K-Means uses a
fixed random seed and `n_init=10`; model evaluation uses shuffled,
stratified 10-fold cross-validation with the same seed. Notebook outputs are
cleared so that results are generated by the installed environment rather
than being mistaken for current results.

The notebook uses `dataset_1.csv` by default. Change the dataset path in the
first code cell when evaluating another prepared dataset. The CSV must provide
the `data` and `label` columns expected by the preprocessing code.

## Cluster-count configurations used in the paper

The paper also reports experiments with 12 and 14 K-Means clusters. These
configurations are not added to the main 10-cluster notebook so that the
notebook remains a focused example of the `k = 10` analysis. The corresponding
experiments are available in
[`model_amp_recursive_dataset1_kmeans.ipynb`](./model_amp_recursive_dataset1_kmeans.ipynb)
and use the same recursive procedure, checkpoints, and 10-fold SVM evaluation.

To reproduce either configuration in the main workflow, change only the
cluster-count parameter:

```python
MANUAL_K_CLUSTERS = 12  # or 14
CHECKPOINTS = [2, 3, 4]
```

## Repository contents

- `amp_recursive_kmeans.ipynb`: `k = 10` recursive K-Means
  and SVM workflow.
- `model_amp_recursive_dataset1_kmeans.ipynb`: dataset-1 experiments for
  `k = 12` and `k = 14`, including SVM, Random Forest, and XGBoost sections.
- `model_amp_recursive_dataset2_kmeans.ipynb`: corresponding experiments for
  the second prepared dataset.
- `dataset_1.csv`, `dataset_2.csv`: prepared feature tables used by the
  recursive experiments.

## Environment

The notebooks use Python 3.12 with the following pinned packages:

- `ipykernel==7.2.0`
- `numpy==2.4.2`
- `pandas==3.0.1`
- `scikit-learn==1.8.0`
- `scipy==1.17.1`
- `statsmodels==0.14.6`
- `xgboost==3.2.0`

Create and activate a virtual environment, then install the dependencies from
[`requirements.txt`](./requirements.txt):

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Run the notebooks from the repository root so relative dataset paths resolve
correctly. Package installation belongs in `requirements.txt` or the
environment setup, not in an executable notebook cell.
